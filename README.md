## ✨ Key Features

### 🧠 Dual-Engine Analysis
* **Multi-API Comparison:** Side-by-side analysis using **Standard (Flash)** and **Expert (Pro)** NLP engines.
* **Discrepancy Highlighting:** Automatically flags "Sentiment Drift" when different APIs disagree on classification.
* **Confidence Scoring:** Real-time probability metrics ($0.0$ to $1.0$) for Positive, Negative, and Neutral tones.

### 📈 Power BI-Style Analytics
* **KPI Tiles:** Global satisfaction scores, engine variance, and semantic volume tracking.
* **Dynamic Visualizations:**
    * **Sentiment Area Chart:** Tracking emotional trends over time.
    * **Radar Analysis:** Visualizing the "Confidence Profile" of text.
    * **System Heatmap:** Measuring model reliability and performance clusters.
    * **Keyword Extraction:** Identifying primary sentiment drivers visually.

### 🎨 Human-Centric Design
* **Mood-Responsive UI:** The dashboard background shifts colors (Pastel Emerald, Rose, or Lavender) based on the emotional tone of results.
* **AI Improvement Engine:** A "💡 Improve" feature that suggests constructive rephrasing for negative content.
* **Batch Processing:** Drag-and-drop CSV/JSON support for analyzing thousands of rows.
* **Responsive Layout:** Optimized for mobile, tablet, and desktop viewing.
